# mycord Documentation

Welcome to the official mycord docs site.

mycord is a minimalist Discord bot wrapper for `discord.py` with built-in SQLite management and automatic `.env` support.

## Quick links

- [Installation](installation.md)
- [Getting Started](getting-started.md)
- [API Reference](api.md)
- [Examples](examples.md)

## What mycord provides

- One import: `import mycord`
- `mycord.Bot` for simplified bot startup
- Direct database access through `mycord.DB`
- Automatic `.env` loading with `python-dotenv`
- Cog loading convenience via `bot.autoload_cogs()`

## Ready to use

To run the docs locally:

```bash
pip install mkdocs
mkdocs serve
```

Visit the site and explore the API, examples, and installation instructions.
